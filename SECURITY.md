# Security

Do not put API keys, session cookies, or `.dev.vars` in this repository. CorroborateMe secrets start with `aa_` - treat them like passwords.

This repo is a **catalog stub**. It does not accept traffic, store data, or validate keys. The hosted MCP server is [https://corroborateme.com/mcp](https://corroborateme.com/mcp).

## Reporting a vulnerability

Contact [support@cnrcode.com](mailto:support@cnrcode.com) or use the contact listed on [corroborateme.com/.well-known/security.txt](https://corroborateme.com/.well-known/security.txt). Do not open a GitHub issue that includes a live key or customer data.

## Client configs

If you paste an MCP config into a gist, chat, or PR, replace the secret with `aa_...` first.
